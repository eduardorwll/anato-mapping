# ADR-0008: Minimalist Functional UI — Zero Filler Contract

- **Status:** Accepted
- **Date:** 2026-11-20

## Context
Curators and students need an unobstructed view of anatomical specimens with zero visual noise.

## Decision
Enforce a strict zero-filler policy: no welcome paragraphs, no decorative copy, no redundant subtitles, and no idle panels. Every UI element must justify its *why* and *how*, and conditional sections (Folder Drawer, Legend, Bibliography block, Tag pills) render only when functional in the current state.
